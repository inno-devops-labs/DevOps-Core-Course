## Task 2: ConfigMap Implementation

Create config.json and ConfigMap via Helm chart.

Relevant files:
- k8s/helm-python/files/config.json
- k8s/helm-python/templates/configmap.yaml
- k8s/helm-python/templates/deployment.yaml

Install or upgrade chart:

```sh
helm upgrade --install helm-python k8s/helm-python
```

Verify pods:

```sh
kubectl get po
```


Verify ConfigMap file in pod:

```sh
kubectl exec <pod-name> -- cat /config.json
```
