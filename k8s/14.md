# Lab 14 — Monitoring Stack and Init Containers

## Summary

In this lab, `kube-prometheus-stack` was installed in the `monitoring` namespace to provide Prometheus, Grafana, Alertmanager, node-exporter, kube-state-metrics, and the Prometheus Operator. The Python application Helm chart was then deployed in the `default` namespace as release `app14`.

The monitoring installation was verified with `kubectl get pods -n monitoring` and `kubectl get po,sts,svc,pvc,cm -n monitoring`. The application deployment was verified with `kubectl get all -n default`, and the service endpoint was obtained through `minikube service`.

## Components of the Monitoring Stack

- **Prometheus Operator** — manages Prometheus-related custom resources and simplifies stack deployment.
- **Prometheus** — collects and stores time-series metrics from Kubernetes components and applications.
- **Alertmanager** — handles alerts generated from Prometheus rules and groups or routes them.
- **Grafana** — provides dashboards and visual exploration of collected metrics.
- **node-exporter** — exports node-level system metrics.
- **kube-state-metrics** — exposes Kubernetes object state as metrics.

## Application Verification

The Python application was deployed successfully in the `default` namespace and exposed through a `NodePort` service. The service URL was obtained with `minikube service`, and the application remained reachable after deployment.

The `/metrics` endpoint returned Prometheus-formatted metrics, confirming that the application instrumentation added in earlier labs remained available.

## Init Containers

An init-container based workload was applied and verified using `kubectl exec`. The evidence shows that a file was prepared before the main container started, which confirms the intended purpose of the init-container.

A second example demonstrated multiple init containers writing to a shared file in sequence. The resulting file contained the expected ordered lines:

- `line1`
- `line2`
- `line3`

This confirms sequential execution of init containers.
