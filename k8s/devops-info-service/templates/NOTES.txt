{{- if .Values.statefulset.enabled }}
This chart deploys `devops-info-service` as a `StatefulSet` (per-pod PVC via `volumeClaimTemplates`), a regular `Service`, and a headless `Service` for stable DNS.

Check resources:
  kubectl get statefulset -l app.kubernetes.io/name={{ include "devops-info-service.name" . }}
  kubectl get pods -l app.kubernetes.io/name={{ include "devops-info-service.name" . }}
  kubectl get pvc
  kubectl get svc -l app.kubernetes.io/name={{ include "devops-info-service.name" . }}

Headless DNS pattern (per pod):
  <statefulset-pod>.{{ include "devops-info-service.headlessServiceName" . }}.{{ .Release.Namespace }}.svc.cluster.local

For progressive delivery (Argo Rollouts), set `statefulset.enabled=false` in values.
{{- else }}
This chart deploys `devops-info-service` as an Argo Rollouts `Rollout` and `Service` (plus `Service` preview when `rollout.strategy=blueGreen`).

To check resources:
  kubectl get rollout -l app.kubernetes.io/name={{ include "devops-info-service.name" . }}
  kubectl get pods -l app.kubernetes.io/name={{ include "devops-info-service.name" . }}
  kubectl get svc -l app.kubernetes.io/name={{ include "devops-info-service.name" . }}

Rollouts CLI:
  kubectl argo rollouts get rollout {{ include "devops-info-service.fullname" . }} -n {{ .Release.Namespace }} -w
  kubectl argo rollouts promote {{ include "devops-info-service.fullname" . }} -n {{ .Release.Namespace }}
  kubectl argo rollouts abort {{ include "devops-info-service.fullname" . }} -n {{ .Release.Namespace }}
{{- end }}

Service access:
{{- if eq .Values.service.type "NodePort" }}
  NodePort: {{ .Values.service.nodePort }}
  In Minikube you can use:
    minikube service {{ include "devops-info-service.fullname" . }} --url
{{- else }}
  Service type is {{ .Values.service.type }}. If you are using Minikube, run:
    minikube tunnel
  Then access via the LoadBalancer IP/hostname:
    kubectl get svc {{ include "devops-info-service.fullname" . }} -o wide
{{- end }}
