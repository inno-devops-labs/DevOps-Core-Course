# Bonus Task — Go Language Justification

## Why Go?
I chose **Go** for the compiled-language bonus because it provides:
- **Single binary deployment**: build once and run anywhere without Python runtime
- **Fast startup and low overhead**: suitable for small services
- **Standard library HTTP server**: `net/http` is sufficient for this lab
- **Cross-platform builds**: easy to build for Linux/Windows/macOS
- **Strong DevOps adoption**: widely used for infrastructure and cloud tooling

## Comparison (brief)
| Language | Pros | Cons |
|---|---|---|
| **Go** | Simple, fast builds, strong stdlib, easy deployment | GC overhead, less expressive type system |
| Rust | Great performance and safety | Higher complexity, slower onboarding |
| Java | Mature ecosystem | Heavier runtime footprint |
| C#/.NET | Great tooling, cross-platform | Runtime dependency, larger packaging |

## Conclusion
Go is a practical choice for DevOps-style services and tools due to portability and easy deployment.
