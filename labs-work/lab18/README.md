# lab18 - reproducible builds with nix

Nix expressions that rebuild the existing Lab 1 / Lab 2 artefacts (`labs-work/app_python/`, `labs-work/app_go/`) with bit-for-bit reproducibility.

## Layout

```
lab18/
├── default.nix     # python derivation - src = ../app_python
├── go.nix          # go derivation - src = ../app_go
├── docker.nix      # reproducible docker image (dockerTools.buildLayeredImage)
├── flake.nix       # bonus - flake exposing all packages + dev shell
├── flake.lock      # generated by `nix flake update`
├── NIX.md          # lab deliverable (writeup, hashes, comparisons, reflection)
├── README.md       # this file
├── .gitignore
└── screenshots/    # evidence captured while running the tasks
```

No copy of the apps is made; both derivations reference the originals via relative `src`.

## Prerequisites

```bash
# Determinate Nix (recommended - flakes enabled by default)
curl --proto '=https' --tlsv1.2 -sSf -L https://install.determinate.systems/nix | sh -s -- install
nix --version
```

If using the official installer, enable flakes manually:

```bash
mkdir -p ~/.config/nix
echo 'experimental-features = nix-command flakes' >> ~/.config/nix/nix.conf
```

## Build the Python App

```bash
cd labs-work/lab18

nix-build                              # creates ./result symlink
./result/bin/devops-info-service       # runs Flask on port 5173
```

Verify reproducibility (same hash after delete + rebuild):

```bash
ORIGINAL=$(readlink result)
nix-store --delete "$ORIGINAL"
rm result
nix-build
test "$(readlink result)" = "$ORIGINAL" && echo "REPRODUCIBLE"
```

## Build the Go App (sub-bonus)

```bash
nix-build go.nix
./result/bin/devops-info-service-go
```

## Build the Reproducible Docker Image

```bash
nix-build docker.nix
docker load < result
docker run -d -p 5174:5173 --name nix-container devops-info-service-nix:1.0.0
curl http://localhost:5174/health
```

Verify the image tarball is byte-identical between builds:

```bash
sha256sum result
rm result && nix-build docker.nix
sha256sum result   # same hash
```

> Building Linux container images on macOS requires a Linux builder. See `NIX.md` -> Challenges for the route used.

## Flake Commands (Bonus)

```bash
nix flake update                       # generate / refresh flake.lock
nix flake check                        # validate the flake

nix build                              # default = python
nix build .#go                         # go binary
nix build .#dockerImage                # docker tarball

nix develop                            # enter dev shell with python + go pinned
```
