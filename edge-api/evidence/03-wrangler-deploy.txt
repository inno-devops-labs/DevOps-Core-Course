# Deploy evidence — two-step workaround
# 
# `wrangler deploy` (single command) fails at the final trigger API call
# from this network with "fetch failed" — likely the Cloudflare connectivity
# issue that labs/lab17.md explicitly warns about for RU traffic.
# 
# The two-step form `versions upload` + `triggers deploy` works around it:
# the bundle upload completes first (slow, ~80s), then a separate, smaller
# call attaches the new version to workers.dev.
