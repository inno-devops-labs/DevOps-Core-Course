# Python Web Application

## Framework Choice

For this lab I used Flask via gunicorn because it is a simple and lightweight Python web framework.
It is a good choice for a small application that only needs to display the current time.

## Best Practices Used

- Dependencies are kept minimal.
- The code is short and easy to read.
- The project structure is simple and clear.

## Coding Standards

- Code is written in PEP 8 format.

## Testing

The application was tested manually in a browser.
After refreshing the page, the displayed Moscow time updates correctly.

## Code Quality

Code quality was ensured by keeping the implementation simple and readable.
