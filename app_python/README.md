## Overview

Web service that provides comprehensive information about itself and its runtime environment. Built with FastAPI for Lab 1 of the DevOps Core Course.

Technologies:

- **FastAPI 0.115.0** - Modern async web framework
- **Uvicorn 0.32.0** - ASGI server with performance extras
- **Pydantic** - Data validation via type hints

Features:

- Service metadata (name, version, framework)
- System information (hostname, platform, CPU, Python version)
- Runtime details (uptime, current time)
- Request information (client IP, user agent)
- Health check endpoint for monitoring
- Persistent visits counter stored in a file
- Separate endpoint for reading the current visits count

## Prerequisites

- Python 3.11 or higher
- pip package manager

## Installation

```bash
# Navigate to app directory
cd app_python

# Create virtual environment
python3 -m venv venv

# Activate virtual environment
source venv/bin/activate  # On Windows: venv\Scripts\activate

# Install dependencies
pip install -r requirements.txt
```

## Docker

**Build image (pattern):**

```bash
docker build -t <image-name>:<tag> .
```

**Run container (pattern):**

```bash
docker run --rm -p <host-port>:8000 <image-name>:<tag>
```

**Pull from Docker Hub (pattern):**

```bash
docker pull <dockerhub-username>/<image-name>:<tag>
```

**Docker Compose for local persistence testing:**

```bash
docker compose up --build -d
curl http://localhost:8000/
curl http://localhost:8000/visits
docker compose restart devops-info-service
curl http://localhost:8000/visits
```

## Running the Application

**Default (0.0.0.0:8000):**

```bash
python app.py
```

**Custom port:**

```bash
PORT=5000 python app.py
```

**Custom host and port:**

```bash
HOST=127.0.0.1 PORT=3000 python app.py
```

**Debug mode:**

```bash
DEBUG=true python app.py
```

## API Endpoints

### GET /

Returns complete service and system information.
To check it out, use:

```bash
curl http://localhost:8000/
```

**Response:**

```json
{
  "service": {
    "name": "devops-info-service",
    "version": "1.0.0",
    "description": "DevOps course info service",
    "framework": "FastAPI"
  },
  "system": {
    "hostname": "hostname",
    "platform": "Darwin",
    "platform_version": "...",
    "architecture": "arm64",
    "cpu_count": 8,
    "python_version": "3.11.0"
  },
  "runtime": {
    "uptime_seconds": 3600,
    "uptime_human": "1 hour, 0 minutes",
    "current_time": "2026-01-24T16:00:00.000Z",
    "timezone": "UTC"
  },
  "request": {
    "client_ip": "127.0.0.1",
    "user_agent": "curl/7.81.0",
    "method": "GET",
    "path": "/"
  },
  "endpoints": [...]
}
```

### GET /health

Health check endpoint for monitoring and Kubernetes probes.

To check it out, use:

```bash
curl http://localhost:8000/health
```

**Response:**

```json
{
  "status": "healthy",
  "timestamp": "2026-01-24T16:00:00.000Z",
  "uptime_seconds": 3600
}
```

### GET /visits

Returns the current persisted visit count from the file configured by `VISITS_FILE`.

To check it out, use:

```bash
curl http://localhost:8000/visits
```

**Response:**

```json
{
  "visits": 3
}
```

### GET /docs

Interactive API documentation (Swagger UI) automatically generated by FastAPI.

**Access:** Open `http://localhost:8000/docs` in browser

## Testing

This project uses `pytest` for unit testing and `flake8` for linting.

Run checks locally:

```bash
# from app_python/
pip install -r requirements.txt
python -m flake8 app.py tests/
python -m pytest -v
```

Run tests with coverage:

```bash
python -m pytest -v --cov=. --cov-report=term --cov-report=xml
```

## Configuration

Configure via environment variables:

| Variable | Default | Description |
| -------- | ------- | ----------- |
| `HOST` | `0.0.0.0` | Server bind address |
| `PORT` | `8000` | Server port number |
| `DEBUG` | `False` | Enable debug logging |
| `APP_NAME` | `devops-info-service` | Service name returned by the API |
| `VISITS_FILE` | `/data/visits` | Path to the persisted visits counter file |

**Example:**

```bash
HOST=127.0.0.1 PORT=3000 DEBUG=true VISITS_FILE=./data/visits python app.py
```
